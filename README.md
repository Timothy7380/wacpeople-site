# WACPEOPLE — website redesign concept

Single-page homepage for WACPEOPLE (a network of reliable creatives), designed in the style of the Awsmd "SaaS Website Design" reference.

- `index.html` — the whole site (HTML, CSS, JS and compressed images in one file)
- Full-resolution photos in the click-to-view gallery load from wacpeople.com

## Hosting on GitHub Pages
Settings → Pages → Source: **Deploy from a branch** → Branch: `main` / `(root)` → Save.
The site will be live at `https://<your-username>.github.io/<repo-name>/` within a minute or two.
